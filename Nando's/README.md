# Nando’s ClimaPro

Base inicial do sistema de gestão da Nando’s Ar-Condicionado.

## Rodar localmente
- Node.js 20.9 ou superior
- `npm install`
- `npm run dev`

## Publicar
Conecte este repositório ao Netlify usando o comando de build `npm run build`. O plugin Next.js do Netlify deve detectar o framework.

## Atenção
Esta versão é uma fundação funcional de cadastros locais. Não possui ainda autenticação segura, banco Neon nem sincronização entre dispositivos. Não substitui o sistema antigo e não importa automaticamente os dados do Supabase.
