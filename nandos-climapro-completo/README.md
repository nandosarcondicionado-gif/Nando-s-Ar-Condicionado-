# Nando's ClimaPro - Sistema Completo de Gestão Empresarial

Sistema completo de gestão para serviços de climatização, refrigeração e assistência técnica.

## 🚀 Módulos Integrados (14 Módulos)
1. **Clientes e Equipamentos**: Busca de CEP automática via ViaCEP e cadastro de múltiplos aparelhos por cliente.
2. **Orçamentos Inteligentes**: Cálculo automático de mão de obra e insumos, desconto %, PDF e link para WhatsApp.
3. **Ordens de Serviço (OS Dupla)**: Separação estrita da OS do Cliente (com valores) e OS do Técnico (sem valores).
4. **Agenda Inteligente**: Visão diária, semanal e mensal com capacidade de atendimento.
5. **Almoxarifado e Estoque**: Baixa automática de materiais com a conclusão das OS.
6. **Financeiro e Caixa**: Fluxo de caixa em tempo real e cálculo da margem de lucro real.
7. **Área do Técnico (Campo)**: Aplicativo mobile com rotas, checklists e fotos.
8. **Administração e Usuários**: Permissões e níveis de acesso (ADM, Técnico, Cliente).
9. **Contratos Mensais**: Manutenções preventivas programadas com alertas.
10. **Relatórios e Indicadores**: Indicadores de rentabilidade, faturamento e perdas.
11. **Assistente Técnico Inteligente**: Base de conhecimento com códigos de erro por fabricante.
12. **Área do Cliente**: Portal de aprovação de orçamentos e consulta de garantias.
13. **Comunicação Automática**: Avisos via WhatsApp (wa.me) e lembretes de visitas.
14. **Funcionamento Online e Offline**: Suporte PWA com IndexedDB e sincronização.

## 🛠️ Pilha Tecnológica
- **Framework:** Next.js (App Router) + TypeScript
- **Estilização:** Tailwind CSS (Paleta Azul-Marinho / Azul-Turquesa)
- **Ícones:** Lucide React
- **Banco de Dados:** Neon PostgreSQL

## 📦 Como rodar localmente

```bash
# Instalar dependências
npm install

# Rodar servidor de desenvolvimento
npm run dev
```
