# Nando’s ClimaPro

Nova plataforma de gestão da Nando’s Ar-Condicionado.

## Desenvolvimento
1. Instale Node.js 20 ou superior.
2. Execute `npm install`.
3. Copie `.env.example` para `.env.local` e preencha as credenciais quando o banco estiver configurado.
4. Execute `npm run dev`.

## Atenção
Este pacote é a fundação visual e técnica inicial, não o sistema completo. Não cadastre dados reais nem use para operar a empresa até implementar e testar autenticação, banco, permissões, módulos e sincronização.

Consulte `docs/PLANO-DO-PROJETO.md` e `database/README.md`.
